# 离线恢复码算号器

统一名称和编号以 [`docs/统一术语表与UI映射.md`](../docs/统一术语表与UI映射.md) 为准：恢复设备号为 `REC-03`，计算日期为 `REC-04`，当日恢复码为 `REC-05`。

双击 `打开恢复码算号器.bat`，输入家长手机恢复页面显示的：

1. 恢复设备号；
2. 计算日期。

点击 `Calculate` 即可得到 8 位恢复码。点击 `Copy code` 可复制结果。

算号器完全离线运行，不需要孩子手机或客服电脑联网。日期必须以手机恢复页面显示的日期为准，不要自行换算。

也可以在 PowerShell 中使用命令行模式：

```powershell
.\recovery-code-calculator.ps1 -NoGui -DeviceId "7D4A-92FC-381B-6E20" -Date "2026-07-26"
```

固定自检向量：

- 设备号：`7D4A-92FC-381B-6E20`
- 日期：`2026-07-26`
- 结果：`19381938`

每次修改 App 的 `RecoveryCodeEngine`、设备号规范化规则、日期格式或主密钥后，必须同步修改本工具，并保持固定自检向量与 Android 单元测试一致。
